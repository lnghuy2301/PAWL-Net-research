# Local research data

This tree is excluded from Git except for directory documentation. See [the data guide](../docs/data.md) for schemas, availability, and quality findings.

- `raw/`: annual arrays `City_YYYY.npy`, shape `(12, H, W, 9)`.
- `patches/train/`: 2015–2022 training/validation patches.
- `patches/test/`: 2023–2024 test patches.
- `archives/`: preserved original compressed data.
